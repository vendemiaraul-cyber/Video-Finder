    Checking…

    Turn SearXNG on (on a computer with Docker):

    1. Download MeoDeo: git clone https://github.com/vendemiaraul-cyber/Video-Finder
    2. In that folder run docker compose up -d
    3. Open http://localhost:8787, or from your phone on the same Wi-Fi, http://<computer's IP>:8787

    Already have SearXNG? Turn its JSON API on (search.formats: [html, json]), then run SEARXNG_URL=http://your-searxng npm start. Leave the address above empty when you open MeoDeo from its own server.

    🍪 Cookies

    Some sites only play a video after you accept their cookies or sign in. What should MeoDeo do with those videos?

    Some browsers (Safari especially) limit cookies inside other websites. If a video stays blank, use "Watch on …" under the player.
