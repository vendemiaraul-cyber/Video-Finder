# MeoDeo SearXNG

SearXNG for [MeoDeo](https://github.com/vendemiaraul-cyber/Video-Finder), with the JSON API on and the limiter off.

Keep this Space **private**: MeoDeo's Cloudflare function reaches it with a Hugging Face token (`HF_TOKEN`), and nobody else can use it.

Set the Space secret `SEARXNG_SECRET` to any long random string.
